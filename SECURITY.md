# Security Policy

## Supported Versions

This is a best-effort reference sample rather than a maintained product.

| Version | Security updates |
| --- | --- |
| Latest `main` | Best effort |
| Older commits | Not supported |

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** flow on the repository's Security tab to submit a private report.

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues. These are goals rather than a service-level agreement for this reference sample.

## Disclosure Policy

Please allow time to investigate and publish a fix before disclosing details publicly. After a fix is available, coordinated disclosure is welcome.
